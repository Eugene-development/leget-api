# leget-api

> 📖 **Полная документация:** [`docs/modules/leget-api.md`](../../docs/modules/leget-api.md)

Laravel 11 + GraphQL (lighthouse). Ядро платформы: рендеринг сайтов, каталоги, биллинг, система
дизайн-компонентов. Взаимодействует с клиентами (leget-front, leget-main) через GraphQL.

- **Назначение, env, команды и связи с другими модулями** → см. `docs/modules/leget-api.md`
- **Правила для AI-агента** → см. `AGENTS.md` в корне проекта

### Подпись на фотографиях мебельного проекта

Форма создания проекта передаёт необязательный `image_caption` в
`upsertMebelProject`: `text` (1–120 символов), `position` (`left`, `center`, `right`),
`font_size` (12–160 px исходного фото), `opacity` (0–100; 0 — невидимый текст),
`color` (`#RRGGBB`), `padding` (0–100 px), `bold` (boolean).
Одна подпись применяется ко всем новым фотографиям. Сохранённые фотографии при
редактировании не меняются. Длинная строка уменьшается до доступной ширины.

`ProjectImageCaption` использует Intervention Image 3 / GD и DejaVu Sans из
установленной зависимости dompdf (включая кириллицу). На сервере необходим GD
с FreeType, JPEG, PNG и WebP; production Dockerfile включает эти расширения.
При выкладке требуется `composer install` и пересборка backend-образа.
Фотографии для подписи ограничены 16 Мп, минимум 32 px по каждой стороне и 10 МБ.

`MebelProjectImages` проверяет принадлежность загрузки владельцу и сохраняет
подписанную WebP-копию в Яндекс Object Storage. Исходник не перезаписывается.
Имя копии зависит от содержимого и настроек: повтор запроса не наносит подпись
повторно. Ошибка обработки или записи не сохраняет проект частично.
