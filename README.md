# leget-api

> 📖 **Полная документация:** [`docs/modules/leget-api.md`](../../docs/modules/leget-api.md)

Laravel 11 + GraphQL (lighthouse). Ядро платформы: рендеринг сайтов, каталоги, биллинг, система
дизайн-компонентов. Взаимодействует с клиентами (leget-front, leget-main) через GraphQL.

- **Назначение, env, команды и связи с другими модулями** → см. `docs/modules/leget-api.md`
- **Правила для AI-агента** → см. `AGENTS.md` в корне проекта
